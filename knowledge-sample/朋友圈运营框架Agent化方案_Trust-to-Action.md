# Trust-to-Action Agent 化方案（合成示例）

## 决策信封

每次模型输出都放入候选信封，包含任务类型、业务证据、知识引用、SKILL 路由、假设、冲突、测量计划、增长姿态、模型元数据和全部版本绑定。候选不能直接写入业务对象，必须由对应角色原样采用、修改后采用或拒绝。

## 版本血缘

MarketingBrainVersion 原子绑定四类代码化 Prompt、知识包、企业事实、检索器、模型路由和确定性策略。任一绑定变化会让待处理候选过期。采用后的历史记录保留原版本，不因回滚自动反转已经发生的业务写入。

## 安全边界

模型不输出隐藏推理过程，只提供可核对摘要。未知引用、无依据事实、隐私泄露、越级迁移和证明门禁失败均阻断。AI 不自动执行任何外部动作。
